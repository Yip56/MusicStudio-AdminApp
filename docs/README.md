## Conventions

- One guide per audience, named `user-guide-<audience>.md`, all directly in `docs/`.
- Short numbered steps, plain language, one section per task, a short FAQ at the end.
- Screenshots are placeholders written as `![description](TODO)` — replace `TODO` with the image path
  (put images in `docs/images/`) when you have them.
- **Whenever a teacher-facing feature changes, update `user-guide-teacher.md` in the same change.**
  The same goes for the admin guide once it exists.
